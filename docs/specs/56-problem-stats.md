# 마이페이지 카테고리·난이도별 풀이 통계 (#56)

- 기준 SHA `ab718be5e5934731b1d466e3cb22a155742aee4d`
- 로그인한 사용자의 `GET /api/users/me/stats` 응답에 `categoryDifficulties` 배열을 추가한다. 각 항목은 `category`, `difficulty`, `attemptedCount`, `solvedCount`를 담는다. 비로그인 응답은 401 `A001`이다.
- 본인의 전체 기간 정식 제출 가운데 기존 통계가 사용하는 일곱 판정(정답, 오답, 컴파일·실행 오류, 시간·메모리·출력 제한 초과)을 집계한다. 문제별로 시도와 정답을 각각 한 번만 센다.
- 문제의 현재 카테고리와 난이도를 사용한다. 등록된 조합에 해당하는 제출이 없으면 두 값은 0이고, 문제가 하나도 없으면 빈 배열을 반환한다.
- 카테고리는 이름 오름차순, 같은 카테고리의 난이도는 Difficulty 순서로 반환한다. 미지정 난이도는 UNRATED다.
- 읽기 전용 트랜잭션에서 집계 쿼리 한 번으로 문제별 시도·정답 여부를 조회하고, 기존 통계와 같은 문자열 비교 규칙으로 조합을 묶는다. 스키마와 데이터 쓰기는 없다.
- 공개 프로필은 기존 통계 응답을 유지한다. 프런트 화면 변경은 범위 밖이다.
