# 서버 시간대 고정 (#86)

기준 SHA: `e12df7e`

## 기능: 서버 기본 시간대를 한국 시간으로 고정
- 목적: 서버를 어디서 실행하든(Docker는 UTC, 개발 PC는 한국) 사용자가 제출 시간·작성 시간을 실제 한국 시간으로 본다
- API: 변경 없음. 시간대 없는 시각(`LocalDateTime`) 응답이 한국 시간이 된다
- 데이터: 스키마 변경 없음. 수정 전 UTC 환경에서 저장된 기존 시각은 그대로 남아 9시간 이르게 보인다(이번 범위에서 변환하지 않는다)
- 규칙: 애플리케이션 시작(`main`) 시 JVM 기본 시간대를 `Asia/Seoul`로 정한다. 잔디·연속 풀이처럼 기본 시간대를 한국 시간으로 바꾸던 계산은 결과가 같다
- 오류: 없음
- 트랜잭션 / 동시성: 없음 / 성능: 없음
- 범위 밖: 기존 데이터 변환, 응답에 시간대 표기 추가
- 재현 조건: 서버 JVM 시간대가 UTC일 때 13:52(KST)에 제출하면 `createdAt`이 04:52로 응답된다
