## 기능: 관리자 회원 생성
- 목적: 팀원 몇 명이 코딩테스트 문제를 등록 수정 삭제할 수 있게 ADMIN 권한을 준다. 관리자는 적고 거의 바뀌지 않는다
- API: 새 API 없음. `POST /auth/login` 응답 모양 그대로이고 토큰의 `role` 클레임만 달라진다
- 데이터: DB 변경 없음. 스키마 영향 없음
- 규칙: 환경변수 `ADMIN_EMAILS`(쉼표 구분, 기본 빈 값)에 있는 이메일로 로그인하면 `ADMIN`, 나머지는 `USER` 토큰을 발급한다
  - 이메일은 앞뒤 공백을 빼고 대소문자를 무시해 비교한다
  - 권한은 다음 로그인부터 적용된다. 목록에서 빼도 이미 받은 토큰은 만료(최대 30분)까지 ADMIN으로 동작한다
- 오류: 새 오류 없음. ADMIN이 아니면 기존처럼 문제 쓰기에서 403
- 설정: `admin.emails: ${ADMIN_EMAILS:}`를 `@ConfigurationProperties` record `AdminProperties`로 받는다
- 트랜잭션: 해당 없음 / 동시성: 해당 없음(설정값 읽기만) / 성능: 해당 없음
- 범위 밖: 관리자 승격 해제 API, users.role 컬럼, 요청마다 권한 재확인
