## 기능: 관리자 이메일 가입 차단 (버그 수정)
- 목적: `ADMIN_EMAILS`에 있는 이메일을 다른 사람이 먼저 가입해 관리자 권한을 얻지 못하게 막는다
- 재현: `ADMIN_EMAILS`에 있지만 아직 가입하지 않은 이메일로 누구나 `POST /auth/signup`에 성공하고, 그 계정으로 로그인하면 ADMIN 토큰을 받는다
- API: `POST /auth/signup`
  - 이메일이 `ADMIN_EMAILS`에 있으면 409 `U001` "이미 사용 중인 이메일입니다." (중복 이메일과 같은 응답이라 관리자 이메일인지 드러나지 않는다)
  - 그 밖의 요청·응답은 그대로다
- 데이터: DB 변경 없음. 스키마 영향 없음
- 규칙
  - 로그인과 같은 방식(`AdminProperties.isAdmin`, 목록 쪽 앞뒤 공백 무시, 대소문자 무시)으로 비교한다
  - 이미 가입된 관리자는 영향 없다. 로그인하면 그대로 ADMIN 토큰을 받는다
  - 관리자 추가 순서: 일반 회원으로 가입 → `ADMIN_EMAILS`에 추가
- 오류: 새 오류 없음. 기존 `U001` 재사용
- 트랜잭션: 기존 가입 트랜잭션 그대로 / 동시성: 해당 없음(설정값 읽기만) / 성능: 해당 없음
- 범위 밖: 이미 다른 사람이 가져간 관리자 계정 정리(운영 DB에서 따로 확인), `users.role` 컬럼, 이메일 인증
