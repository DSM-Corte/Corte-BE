# 내 티어·순위 연동과 랭킹 기준 수정

- 이슈: #91
- 기준 SHA: ab718be
- 공개 목록은 기존 GET /api/leaderboard 계약을 유지한다. 로그인 회원은 GET /api/leaderboard/me로 같은 전체 순위표에서 자신의 Entry를 받는다. 비로그인은 401 A001, 사라진 회원은 404 U003이다.
- 모든 회원을 포함한다. 기존 점수와 티어 계산을 유지하고, 점수 내림차순 → 가입 시각 오름차순(기존 회원의 null 먼저) → ID 오름차순으로 전체 순위를 매긴다. 필터·정렬·페이지는 이후에 적용한다.
- users.joined_at을 nullable로 추가한다. 기존 회원은 null, 신규 가입의 시각은 JPA 감사 기능으로 기록한다.
- 목록과 내 순위는 읽기 전용이며 회원, 제출, 지급 기록을 각각 일괄 조회한다. 기존 조회처럼 전체 집계는 Java에서 하고 목록만 페이지로 자른다.
- 마이페이지에 기존 내 티어 API의 티어·점수를 표시하고, 리더보드 상단에 로그인 회원의 전체 순위를 표시한다.
